TEXT REPRESENTATION

For each element return BOTH:

1. text_visible
Exact visually rendered text including visible line breaks and hyphenation.

2. text_logical
Normalized logical text suitable for translation.
Repair soft hyphenated line wraps where appropriate.

Example:

text_logical:

BOX TYPES

Return BOTH:

2. render_box
The larger layout region intended for translated text rendering.
