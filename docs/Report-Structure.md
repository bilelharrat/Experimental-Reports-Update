Version 1 suggestions:

针对**中后期股权投资（Growth / Late Stage）**，我建议报告不要沿用早期 VC 那种“团队 \+ 产品 \+ TAM \+ 融资”的简单框架，而应更接近**成长股研究 \+ PE underwriting \+ IPO/退出分析**：核心回答三个问题——**是不是好公司、现在价格是否值得买、未来3–5年能否以足够确定性退出并实现目标回报。**

下面这个框架比较适合你们目前关注的 OpenAI、Anthropic、Databricks、Stripe、Together AI、Fireworks AI、Harvey、Glean 等中后期项目，也适合直接作为投资委员会 IC Memo 的标准模板。

# **中后期股权投资分析报告框架**

## **一、Executive Summary｜投资结论**

建议控制在 **1–2页**，让投资委员会先看到结论。

**1\. 公司一句话定位**

* 公司做什么  
* 所处赛道  
* 行业地位  
* 核心客户  
* 当前规模

例如：

> Databricks 是企业 AI 时代领先的数据与 AI 基础设施平台，正在从 Lakehouse 向企业统一 Data \+ AI Platform 演进。

**2\. 核心投资逻辑 Investment Thesis**

建议只写最重要的 **3条**：

* 为什么这是一个足够大的市场？  
* 为什么这家公司能够成为/保持 Top 1–3？  
* 为什么现在这个估值仍然有投资回报空间？

每条最好都有数据支撑。

**3\. 核心财务与估值**

| 指标 | 当前 | 未来3年 |
| ----- | ----- | ----- |
| Revenue / ARR |  |  |
| YoY Growth |  |  |
| Gross Margin |  |  |
| EBITDA/FCF Margin |  |  |
| 当前估值 |  |  |
| EV/Revenue |  |  |
| 预计IPO估值 |  |  |

**4\. 投资建议**

明确给出：

**Strong Buy / Buy / Watch / Pass**

并给出：

* 建议投资金额  
* 基金占比  
* Entry Valuation  
* Base Case MOIC  
* Bull Case MOIC  
* Bear Case MOIC  
* Expected IRR  
* 预计持有期

---

# **二、Company Overview｜公司概况**

重点是把公司“讲清楚”，而不是堆历史资料。

包括：

* 成立时间、总部  
* 创始人及核心管理团队  
* 历史融资  
* 主要投资人  
* 最新估值  
* 员工人数  
* 产品矩阵  
* 主要客户  
* 收入规模  
* 全球布局

建议增加一个非常重要的部分：

### **公司发展阶段判断**

判断它现在属于：

**Product-Market Fit → Scale-up → Category Leader → Pre-IPO → Public Market Candidate**

中后期投资尤其要判断：

> 公司已经证明了什么？还有什么尚未证明？

---

# **三、Market Opportunity｜行业与市场空间**

这一部分不要只写一个 TAM 数字。

建议拆成：

### **1\. 市场定义**

公司真正参与的是哪个市场？

例如 AI Infrastructure 可以进一步拆成：

Compute → Model → Inference → Data Infrastructure → Agent Infrastructure → Application

### **2\. TAM / SAM / SOM**

分别测算：

* 当前市场规模  
* 2030年市场规模  
* CAGR  
* 公司现实可获取市场

### **3\. 市场增长驱动力**

回答：

> 为什么未来5–10年这个市场会持续增长？

比如：

* AI token consumption  
* 企业AI渗透率  
* 推理成本下降  
* AI Agent adoption  
* 数据增长  
* 软件预算迁移

### **4\. 市场天花板**

这是中后期投资非常重要的一项：

> 如果公司成功，最终可能成为 $20B、$100B，还是 $500B 公司？

---

# **四、Product & Business Model｜产品与商业模式**

这一部分回答：

> 客户到底为什么付钱？

分析：

**产品**

* 核心产品  
* 产品矩阵  
* Workflow  
* 客户使用场景  
* Mission-critical程度

**商业模式**

* Subscription  
* Usage-based  
* Transaction fee  
* SaaS  
* Infrastructure consumption  
* Marketplace  
* Hybrid

重点研究：

**收入 \= 客户数量 × 客单价 × 使用量 × 留存**

尤其关注：

* ASP / ACV  
* NRR  
* Gross Retention  
* Usage Growth  
* Upsell  
* Cross-sell

---

# **五、Competitive Landscape｜竞争格局**

这是我认为整个报告中**最重要的三个章节之一**。

不要只是列竞争对手。

建议画一个完整产业地图：

**Upstream → Company → Downstream**

然后分析：

| 公司 | 产品 | 收入 | 增速 | GM | 客户 | 估值 | 核心优势 |
| ----- | ----- | ----- | ----- | ----- | ----- | ----- | ----- |
| Target |  |  |  |  |  |  |  |
| Competitor A |  |  |  |  |  |  |  |
| Competitor B |  |  |  |  |  |  |  |

最终回答三个问题：

**① 谁是现在的第一名？**

**② 3–5年以后谁可能是第一名？**

**③ 为什么？**

这比简单判断“公司是不是好公司”重要得多。

---

# **六、Moat｜护城河**

建议单独成章。

可以从八个维度判断：

**Technology / Data / Distribution / Ecosystem / Switching Cost / Network Effect / Brand / Scale**

但最关键的问题是：

> 如果 Google、Microsoft、Amazon、OpenAI 或一家资金充足的创业公司投入 $5B 来做同样的事情，为什么仍然无法轻易取代它？

同时判断：

### **护城河是在扩大还是缩小？**

这是 AI 投资尤其重要的问题。

因为很多AI公司的产品很好，但**技术差异可能随着基础模型进步迅速商品化**。

---

# **七、Customers & Unit Economics｜客户与单位经济模型**

中后期公司必须从“故事”进入“数字”。

重点看：

* Customer Count  
* Fortune 500 penetration  
* Top 10客户集中度  
* ACV  
* NRR  
* Gross Retention  
* CAC  
* CAC Payback  
* LTV/CAC  
* Sales Efficiency  
* Magic Number

尤其关注：

### **Revenue Quality**

把收入分成：

**High-quality recurring revenue**

和

**Low-quality / concentrated / project-based revenue**

例如一家收入 $1B、70%来自两个客户的公司，与收入 $1B、来自5,000个企业客户的公司，估值逻辑完全不同。

---

# **八、Financial Analysis｜财务分析**

建议至少分析过去3年 \+ 未来3–5年。

### **Revenue**

* Revenue  
* ARR  
* YoY Growth  
* Organic Growth

### **Profitability**

* Gross Margin  
* Contribution Margin  
* EBITDA  
* Operating Margin  
* FCF

### **Efficiency**

非常推荐加入：

**Rule of 40**

以及：

**Incremental Gross Profit / Incremental Opex**

看公司增长质量是否改善。

最终判断：

> 公司增长是在越来越健康，还是靠越来越多资本换增长？

---

# **九、Management & Governance｜团队与治理**

中后期阶段与早期最大的区别之一：

**创始人优秀已经不够，必须判断能否管理一家 $10B–$100B 公司。**

重点看：

* Founder vision  
* Execution  
* Recruiting  
* Capital allocation  
* Management depth  
* CFO  
* CRO  
* CTO  
* Board  
* Governance

特别研究：

### **Founder Dependence**

公司是否过度依赖一个创始人？

以及：

### **Public-company readiness**

管理层是否已经具备上市公司能力？

---

# **十、Valuation｜估值分析**

这是中后期投资报告的核心。

建议至少使用三种方法。

### **① Comparable Companies**

选择上市可比公司：

**EV / Revenue**  
**EV / ARR**  
**EV / EBITDA**  
**P/E**  
**FCF Yield**

然后进行：

**Growth-adjusted multiple**

因为 20% 增长和 80% 增长的公司不能简单比较 EV/Revenue。

### **② Precedent Transactions**

参考：

* 最近融资  
* Secondary transactions  
* M\&A  
* 同行业私募融资

### **③ DCF / Long-term Earnings Power**

对于已经接近盈利的 Stripe、Databricks 等尤其有意义。

最终得到：

**Fair Value Range**

例如：

$140B–180B

而不是只给一个数字。

---

# **十一、Return Analysis｜3–5年回报测算**

这是我认为**整个中后期投资报告最重要的一页**。

核心公式：

**Future Equity Value**  
**÷ Entry Equity Value**  
**\= MOIC**

建立三个情景：

|  | Bear | Base | Bull |
| ----- | ----- | ----- | ----- |
| 2030 Revenue |  |  |  |
| Growth |  |  |  |
| Exit Multiple |  |  |  |
| Exit Valuation |  |  |  |
| MOIC |  |  |  |
| IRR |  |  |  |

一定把：

**Revenue Growth**

和

**Multiple Expansion / Compression**

分开。

因为很多中后期投资亏钱不是公司没增长，而是：

> 公司收入增长了3倍，但估值倍数从30× Revenue下降到10×。

---

# **十二、Exit Analysis｜退出分析**

中后期投资必须从进入第一天就考虑退出。

分析：

**IPO**

* 最早可能IPO时间  
* IPO readiness  
* IPO revenue threshold  
* Public market comps  
* Lock-up

**M\&A**

* Potential acquirers  
* 战略价值  
* 反垄断风险

**Secondary**

* 二级市场流动性  
* Tender offer  
* Existing secondary pricing

最后形成：

**2027 / 2028 / 2029 / 2030 Exit Map**

---

# **十三、Risk Analysis｜风险分析**

不要写泛泛的“市场风险、竞争风险”。

建议只写真正可能让投资 thesis 失败的 **Top 5 Risks**。

每个风险回答：

**Risk → Probability → Impact → Leading Indicator → Mitigation**

例如：

> Open-source model performance rapidly converges with proprietary models → API pricing collapses → gross margin falls → valuation multiple compresses.

这样风险分析才真正对投资决策有价值。

---

# **十四、Catalysts｜未来12–36个月催化剂**

这一部分非常适合 Growth Investment。

例如：

* 新产品  
* ARR突破  
* 大客户  
* Margin改善  
* 国际扩张  
* Strategic partnership  
* 新一轮融资  
* Tender  
* IPO filing  
* IPO

建立一个：

**Catalyst Timeline**

这样可以判断什么时候可能发生估值重估。

---

# **十五、Investment Decision｜最终投资决定**

最后一页只回答六个问题：

**1\. Is this a great company?**

**2\. Is this a great industry?**

**3\. Does it have a durable moat?**

**4\. Can revenue/earnings grow 3–5×?**

**5\. Is today's valuation attractive?**

**6\. Can we achieve our required return?**

最后给出：

> **Recommendation: INVEST**

**Entry valuation:** $XXB  
**Investment:** $XM  
**Fund allocation:** X%  
**Expected holding period:** X years  
**Base MOIC:** X.X×  
**Base IRR:** XX%  
**Downside:** X.X×  
**Target exit:** IPO / Secondary / M\&A

## **我建议你们内部再增加一个「100分投资评分卡」**

如果这是给你们基金建立统一的投资决策体系，我会把所有中后期项目统一按照 **100分**评分：

| 维度 | 权重 |
| ----- | ----- |
| 市场空间与增速 | 15 |
| 行业地位 | 15 |
| 护城河 | 15 |
| 收入增长与质量 | 15 |
| 商业模式/单位经济 | 10 |
| 团队与治理 | 10 |
| 估值 | 10 |
| 退出确定性 | 5 |
| 风险收益比 | 5 |
| **Total** | **100** |

我的建议是设置一个硬门槛：**80分以上进入重点投资名单，70–79分进入 Watch List，70分以下原则上不投。**

尤其对你们现在这种以**中后期 AI Top Players**为核心的基金，我会把整个分析体系浓缩成一句话：

> **Great Market × Category Leader × Durable Moat × High-Quality Growth × Reasonable Entry Price × Visible Exit \= Attractive Risk-Adjusted Return**

而最终 IC 不应该只讨论“这是不是一家伟大的公司”，而应该讨论：**“在今天这个价格买入这家伟大的公司，未来3–5年的风险调整后回报是否足够好？”** 这才是中后期投资和早期VC最核心的区别。

Version 2 suggestions:  
一、执行摘要（投决第一眼核心）

1\. 项目基本概况（行业、赛道、阶段、核心产品）

2\. 本轮融资方案（估值、投前/投后、融资金额、股份比例、稀释方式）

3\. 核心投资亮点（3–5条、最硬核、不可替代）

4\. 核心风险提示（3条以内、真实、致命优先）

5\. 投资结论与建议（推荐投资/审慎投资/暂缓）

二、行业与赛道分析（宏观+中观）

1\. 赛道定义与分类

• 赛道精准定义、上下游结构

• 所处产业链位置、核心价值环节

2\. 行业市场空间

• 现有市场规模、未来3–5年CAGR增速

• 渗透率、替代空间、增量逻辑

• 细分赛道天花板判断

3\. 行业政策与监管环境

• 国家政策导向、鼓励/限制条款

• 监管风险、合规门槛、资质壁垒

4\. 行业竞争格局

• 头部玩家梯队、市场集中度CR3/CR5

• 国内外对标企业、差异化对比

• 行业核心成功要素（技术/渠道/品牌/产能/资金）

5\. 行业趋势判断

• 技术迭代趋势

• 国产化、智能化、出海、降本增效等核心逻辑

三、公司基本面分析（微观核心）

1\. 公司发展历程

• 关键里程碑、产品迭代、客户突破、融资历史

2\. 核心产品与服务体系

• 产品矩阵、技术路线、迭代能力

• 产品解决的行业痛点、刚需程度

• 毛利率结构、高毛利产品占比

3\. 核心壁垒（中后期重点）

• 技术壁垒：专利、算法、工艺、自研体系

• 产品壁垒：差异化、体验、稳定性、迭代速度

• 客户壁垒：粘性、复购、替换成本

• 资质壁垒、产能壁垒、规模壁垒、资金壁垒

4\. 商业模式拆解

• 收入模式：直销/渠道/订阅制/项目制

• 成本结构、费用结构

• 获客模式、客户留存、续费率、回款周期

• 商业闭环是否完整、可复制、可规模化

四、财务数据分析（中后期最重权重）

1\. 历史财务表现（近3年+最新季报）

• 营收、增速、季度环比趋势

• 归母净利润、扣非净利润

• 毛利率、净利率、费用率变化趋势

• 经营性现金流、收现比、净现比

2\. 财务质量判断

• 增长是否可持续

• 利润是否真实、是否依赖补贴/一次性收益

• 现金流健康度、应收账款风险、存货风险

3\. 未来3–5年财务预测

• 营收拆分预测（按产品/客户/区域）

• 毛利率、费用率、净利润预测逻辑

• 关键假设说明（保守/中性/乐观）

五、客户与市场验证（中后期真实性核心）

1\. 核心客户名单、行业头部客户占比

2\. 客户结构集中度风险

3\. 复购率、续费率、单客价值ARPU

4\. 订单储备、在手订单、预收账款

5\. 市场口碑、竞品对比优势

六、团队分析（中后期看稳定性与治理）

1\. 核心创始人背景、行业经验、过往战绩

2\. 核心高管团队完整度、稳定性

3\. 技术团队、销售团队、运营团队配置

4\. 股权结构、历史融资机构阵容

5\. 公司治理、内控体系、股权激励情况

七、竞争格局与对标分析

1\. 直接竞争对手对比（产品、价格、客户、毛利、增速）

2\. 间接替代者、跨界入局者风险

3\. 公司核心竞争优劣势总结

4\. 国内外上市公司对标估值对比

八、本轮融资方案与估值分析（PE投决核心）

1\. 本轮融资要素

• 融资金额、释放股份比例

• 资金用途（研发/扩产/市场/补充现金流）

• 老股转让/增资比例

2\. 估值合理性分析

• 当前PE、PS、PB估值

• 与同业上市公司、一级市场对标估值对比

• 估值溢价/折价原因

• 未来估值消化空间

3\. 退出路径测算（中后期必写）

• 预期上市时间、上市板块

• 并购退出可能性

• 最坏情形兜底逻辑

九、核心投资亮点（精炼版 4–6条）

全部写可验证、硬核、量化的亮点，避免空话

十、核心风险分析与应对措施

1\. 行业风险

2\. 竞争风险

3\. 经营与业绩波动风险

4\. 客户集中度风险

5\. 政策合规风险

6\. 技术迭代风险

7\. 估值风险

每条风险必须附带：对应缓释措施

十一、投资策略与投后赋能计划

1\. 本轮投资策略（重仓/跟投/卡位）

2\. 投后风险监控指标

3\. 机构可提供的资源赋能（产业、客户、合规、资本运作、上市辅导）

十二、最终投资结论

明确给出：  
推荐投资 / 审慎投资 / 不建议投资  
并一句话总结核心逻辑
