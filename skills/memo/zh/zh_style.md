## 中文备忘录写作规范与术语表

这是 BSH 投资备忘录中每一段中文的常设写作要求：无论是把定稿的英文包译成中文、
只修中文的修复轮，还是直接用中文撰写，都适用。中文团队修改的是本文件；
Ben 让 Claude 做 "sync zh → en" 时，改动会同步到代理实际读取的英文版
（skills/memo/zh_style.md）。

### 中文应当读起来像什么
- 按研报的文风写：书面语、短句、判断在前、依据在后。
- 译意思，不译英文句法。在同一个字符串之内，可以把一个长英文句子拆成两个
  中文句子，可以调整从句的先后，也可以把英文的名词短语改写成中文的动词
  结构，让译文读起来像直接用中文写成的。但不得把内容挪到另一个字符串，不得
  合并或拆分字符串，也不得删掉或添加任何论点、限定条件或风险。
- 数字和引用编号一律照原样保留。每一个数字、区间、倍数、百分比和日期，以及
  每一个 `[S#]` / `[C#]` 标记，都要与英文原句完全一致；金额保持英文写法
  （$24M、$1.0B+），与上面的数字规范一致。
- 一个英文术语只对应一个中文译法。同一术语在每一章节、每一次出现都按下面的
  术语表来译，这样并行翻译的各部分才能保持一致。术语表没有收录的词，沿用
  全文第一次出现时的译法。
- 不要照搬英文的对比习惯。"rather than" 和 ", not X" 不必每次都译成"而非"：
  先说清楚它是什么；只有对比本身就是重点时，才用"而非 / 而不是"。
- 去掉翻译腔："进行 + 名词"（进行分析 → 分析）、层层叠叠的"的"字结构、
  中文并不需要的"被"字句、"对于……来说"和"通过……来"之类的架子、每个名词
  前都加的"一个 / 一种"，以及以"的"字收尾的句子。
- 名称沿用共同规则：没有通行中文名的，保留英文名；有通行中文名的，首次出现
  写作"中文名（英文名）"。
- 章节标题、子章节标题和风险卡片的行标签由结构文件和渲染器固定。照抄即可，
  不要重新翻译。

### 待团队确认的译法
- discount（折扣 / 折价）：原术语表没有这一项，而有一份备忘录把同一个
  "discount" 分别写成了折让、折价和折扣。默认：SAFE 或可转票据的转换折扣用
  "折扣"，价格低于可比公司或上一轮用"折价"；两种情况都不用"折让"。
- bear / bull case（悲观 / 乐观情形）：团队原有的术语表写"熊市 / 牛市情形"；
  创始人的报告框架对情景假设写的是"保守 / 中性 / 乐观"；研报通行的说法是
  "悲观 / 乐观情形"。默认用"悲观情形 / 乐观情形"——牛市、熊市说的是市场行情，
  不是情景假设。只把"看跌 / 看涨情形"这类直译列为避免用语，团队如要改回，
  不会让每份备忘录都被标记。
- cash burn / cash runway（现金消耗 / 现金可支撑时间）：团队的稿子写"烧钱"和
  "现金跑道"；共用的翻译规则更推荐"现金消耗"和"现金可支撑时间"，并且不鼓励
  机械地译成"跑道"。默认用共用规则的说法；团队的两个说法都不会被标记。
- MOIC / IRR：原术语表写"回报倍数 / 内部收益率"，翻译规则则要求保留拉丁字母
  缩写。默认：首次出现写作"回报倍数（MOIC）"和"内部收益率（IRR）"，之后
  直接写 MOIC、IRR；表头可以一律用缩写。
- sales pipeline（销售管线）：团队自己的稿子写的是"管线"。默认：首次出现写
  "销售管线"，之后可简称"管线"。
