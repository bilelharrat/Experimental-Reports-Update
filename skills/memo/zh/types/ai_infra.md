## 这一类型是什么
为大模型训练、推理部署及数据工作流提供算力加速、底层调度管理、性能优化与数据流转的底层公司。它们靠承载全行业的模型吞吐与工作负载赚钱。投资的关键在于判断其捕获的是持久的技术系统红利，还是转瞬即逝的供需错配红利。

## 适用与边界
- 适用：推理/训练加速引擎、分布式集群调度编排、高性能通信/网络优化、KV Cache/向量数据库、AI 编译器、异构芯片/ASIC、GPU 算力云原生平台。
- 不适用：基础模型研发实验室、终端垂直 AI 应用、外包数据标注工厂、传统通用 IDC 机房托管。

## 双轨分流法则 (必须严格执行)
投研报告在第一章节必须强制界定标的属于以下哪种路径，严禁混淆评估体系：
*   **路径 A：软件型 AI Infra（轻资产，SaaS / 软件许可 / 按用量计费）**
    *   *核心审查*：代码穿透力、开源商业化分界线、状态黏性、纯软件毛利率（>70%）、NDR（>130%）。
*   **路径 B：算力与硬件型 Infra（重资产，裸金属云 / ASIC 芯片 / 专有集群）**
    *   *核心审查*：资金杠杆率、单卡还本周期（<18-24 个月）、万卡集群 MFU、有效计费利用率、硬件残值减值风险。

## 投资亮点通常落在哪里
- **不可替代的系统级效率压榨** —— 依靠底层软硬件协同优化（P-D 分离、算子融合、高效显存复用），在相同硬件条件下提供显著超越标准开源栈的吞吐量与极低延迟，为客户直接削减 40% 以上的单 Token TCO。
- **有状态的工作流锁死（Stateful Moat）** —— 深度沉淀企业的私有业务数据、高频检索索引、上下文缓存或核心生产调度状态，替换成本极高，而非随时可拔插的无状态代理层。
- **跨平台中立性与生态网络** —— 独立于单一模型厂商与单一云巨头，成为多模型竞争格局下各大企业统一的“模型网关与算力调度路由器”。
- **开源生态商业化闭环** —— 拥有极具号召力的开源技术标准或核心开发者阵地（自下而上 PLG），同时在多租户隔离、高可用容灾、动态弹性伸缩等企业级闭源特性上构建出清晰的变现飞轮。
- **逆周期存活能力** —— 算力云具备自研网络与系统调度软件带来的增值溢价，在芯片供给过剩、硬件租金下行周期中依然能凭借系统能效维持健康正向毛利。

## 报告偏好
- 先测算单项性能指标转化为“真金白银成本优势”的比例，再看技术叙事架构；拒绝一切脱离 TCO 的纸面跑分。
- 严查“巨头兼并窗口”：假设主流开源框架（vLLM、PyTorch）或芯片巨头（NVIDIA）在下一次重大更新中免费提供该功能，标的是否具备独立生存能力？
- 坚决穿透“算力二道贩子”：若无底层通信调度与异构增效软件能力，仅靠高杠杆租赁芯片赚利差的项目，估值严禁按科技软件倍数溢价。
- 区分试用期虚假繁荣与生产级黏性：区分自发开发者 GitHub Star 数量与企业级架构师签单采购的实际转化率。

## 各章节必须承载的类型专属指标
- **系统性能与能效**：P95 / P99 延迟与首字延迟（TTFT）；端到端并发吞吐（Tokens/s）；实际工作负载下的 MFU（模型算力利用率）；网络无损通信吞吐与丢包容忍率。
- **商业与留存（软件轨）**：纯软件 ARR 规模与增速；净金额留存率（NRR）与毛留存率（GRR）；基于用量计费的净扩张斜率；CAC 回收期。
- **运营与资产（硬件/算力云轨）**：服务器实际上架率与计费利用率（Billable Utilization %）；资本开支（CapEx）与债务融资利息成本；单卡投资回收周期（Payback Period）；前三大客户及单一大客户营收占比。
- **交付与合同约束**：已签约不可撤销订单（Backlog）；产能交付延迟违约条款；上游芯片厂商供应配额保供协议（SLA）。

## 成本与经济性堆栈 (必须拆解)
根据双轨属性选择匹配的测算模型：
*   **软件型 Infra 经济性**：
    *   `ARR − 软件交付与客户成功成本 − 托管云资源损耗 = 纯软件毛利 (必须 >75%)`
*   **算力云/集群经济性**：
    *   `算力总收入 − 服务器硬件折旧 − 机房电力与 PUE 运维 − 数据中心网络带宽 − 自研调度研发 = 运营毛利 (健康线 >35%–45%)`

## 失败模式 -> 风险领域
- **开源与巨头生态双向挤压**：顶尖开源推理/调度框架快速演进，主流功能被标准化打包，初创公司自研闭源工具沦为缺乏维护价值的“孤岛”。
- **资产错配与折旧暴雷（算力云）**：借入高息资金采购昂贵硬件，遭遇下游大模型客户违约流失或上游芯片代际降价，计提巨额资产减值。
- **无状态导致的零迁移成本**：工具处于调用链路边缘（如单纯的 API 格式转换、轻量 Prompt 调试），客户随时可以通过几行代码替换服务商。
- **大客户自研反噬**：当最大客户的 AI 业务规模跨过临界点后，自建底层调度架构并组建专用团队，直接抽干初创公司半数以上收入。
- **纸面订单无法交付**：过度承诺万卡级交付能力，但因数据中心电力指标（Power Constraints）、液冷工程缺陷或网络通信故障导致违约退单。

## 红旗
- 核心代码本质是对开源代码库的轻度封装（Wrapper），缺乏自研底层算子与通信优化能力。
- 将社区开源项目的“下载量 / GitHub Stars”伪装成商业吸引力，企业生产环境实际付费转化率极低。
- 算力云毛利率低于 25%，且未将硬件残值折旧计入销售成本（COGS）。
- 单一客户占总营收比重超过 40%，且该客户正在公开招聘同类底层架构工程师。
- 仅提供理想环境下的峰值理论参数（Peak FLOPS），拒绝提供混合长短文本与高并发压力下的实测降速数据。

## 估值模型与退出惯例
- **估值模型**：
  * **纯软件型**：以基础设施软件龙头（如 Snowflake、Datadog、HashiCorp）为标杆，按 EV / 远期 ARR（通常在 10–20x 区间，结合 NRR > 130% 的成长溢价）测算。
  * **算力资产型**：以半导体与新一代数据中心网络为标杆，严格按 EV / EBITDA（8–14x）或基于重置成本（NAV）与现金流折现（DCF）进行保底定价。
- **退出路径**：
  * **独立 IPO**：要求纯软件型标的在 ARR 突破 2 亿美元且保持 Rule of 40 指标；算力型标的需具备跨周期的稳定正向 EBITDA 与电力资产储备。
  * **战略并购**：主要的买方为三大云厂商（Hyperscalers）、网络与芯片巨头（NVIDIA、Broadcom、AMD）以及大型企业软件在位者。尽调必须明确评估各潜在买方发起的反垄断审查阻力。
