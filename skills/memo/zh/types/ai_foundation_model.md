## 这一类型是什么
基于前沿深度学习架构（预训练 + 强化学习后训练 + 推理期计算拓展），自研基础通用或领域前沿基座模型，并通过消费端交互界面、开发者平台 API、企业专有云交付及智能体运行时捕获商业价值的公司。技术是底座，商业胜负取决于算力工程能效与分发生态壁垒。

## 适用与边界
- 适用：通用大语言模型（LLM）、前沿多模态大模型（LMM）、AGI 实验室、全栈自研基座模型平台。
- 不适用：纯 AI 上层应用套壳、无自研模型的微调工作流软件、纯第三方 GPU 算力转租托管、消费级内容生产工具。

## 投资亮点通常落在哪里
- **顶峰智能与持续推演力** —— 在复杂推理（Reasoning）、长任务规划（Agentic Workflows）与高质量代码生成上持续处于全球第一梯队；领先优势跨越 2 代以上模型周期，证明其具有范式创新的组织飞轮而非单次偶然突刺。
- **系统级工程效率红利** —— 在相同芯片集群规格下，拥有业内领先的集群 MFU（>45%）与系统容错韧性，使同参数规模模型的端到端研发与推理服务成本显著低于同行，具备穿越 Token 价格战的成本底牌。
- **分发重力与开发者网络** —— 拥有数百万活跃开发者和数十万企业集成接口，模型成为关键业务流的基础默认环境（Default Architecture），形成强生态互补品黏性。
- **专有数据与后训练合成飞轮** —— 具备自动化形式化验证（Verifiers）、过程奖励模型（PRM）及专有环境交互数据生成管线，摆脱对公开清洗语料枯竭的依赖。
- **资本与战略算力同盟** —— 获得超大规模云厂商（Hyperscalers）或顶级芯片巨头的战略级低成本算力保供、优先芯片配额与联合 GTM 分发渠道支持。

## 报告偏好
- 坚持“先上牌桌、再论胜负、最后拆解单元经济”的逻辑框架；面对前期高额资本支出与账面亏损保持客观，但必须穿透其算力消耗向商业价值的转化速率。
- 拒绝任何单一的公开学术榜单（Benchmarks）宣传，优先采用基于私有动态对抗评测集、工业级代码生成及真实任务闭环胜率（Win-rate vs SOTA）。
- 重点审查“中间层截流风险”：分析下游主要客户是直接调用原生 API，还是通过聚合层路由框架使用；若模型明天降价或提速，客户黏性是否会留在公司。
- 明确区分“事实披露”、“模型推演”与“管理层叙事”，标明关键运营数据的时间戳与置信区间。

## 各章节必须承载的类型专属指标
- **技术与系统指标**：私有对抗评测真实胜率；万卡训练 MFU（%）；单次 Epoch 中断与断点恢复平均耗时；推理 P-D 延迟指标（TTFT 与 ITL）；上下文长度无损检索召回率。
- **商业与收入指标**：真实年化收入（分拆订阅、API、定制企业部署）；企业 API 的净收入留存率（NRR）；按 Token 计费的综合单价与实际毛利率走势；前五大客户及前两大分发渠道的集中度比例（%）。
- **资本与算力指标**：净可用现金及月度净烧钱速率（Net Burn Rate）；现金跑道长度（Runway，以月计）；以年数和未折现美元计的不可撤销算力采购与云租赁合同总额（Compute Commitments）；每消耗 1 美元研发算力所撬动的 ARR 增量。
- **组织与人才指标**：核心技术论文与技术报告作者群留存率；系统架构与算法研究岗位的薪酬与股权激励吸引力；关键人员（Key Person）意外流失对后续模型交付周期的影响评估。

## 经济性堆栈（必须展示）
投研报告必须强制构建并推演以下单 Token 与整体业务经济性链条，并对各项做“公司披露 vs 估算”的标注：
*   **毛收入 (Gross Revenue)**
    *   *− 推理算力直接成本 (Inference Hardware/Cloud COGS)*
    *   *− 训练 CapEx/租赁按期摊销 (Training Amortization)*
    *   *− 数据授权与合成标注成本 (Data Licensing & Labeling)*
    *   *− 服务可用性保障与云基础架构 (Serving Infra & Ingress/Egress)*
    *   **= 贡献毛利 (Contribution Gross Margin)**
    *   *− 核心算法与系统研发薪酬 (R&D Personnel)*
    *   *− 未资本化的探索性实验算力消耗 (Exploratory Training OpEx)*
    *   *− 开发者生态与渠道让利 (Developer Ecosystem & GTM)*
    *   *− 运营、法务合规与数据安全安全对齐 (SGA & Red Teaming)*
    *   **= 真实经营现金流 (Operating Cash Flow / Burn)**

## 失败模式 -> 风险领域
- **技术停滞与开源追平**：算法突破遭遇瓶颈，最新旗舰模型与下一代开源高权重模型未能拉开明显代差，导致高溢价 API 业务面临断崖式流失。
- **算力债务暴雷**：在算力紧缺高点签订了数年昂贵不可撤销的 GPU 租赁长协，当芯片能效迭代或租金大幅下挫时，背负巨额固定成本包袱。
- **渠道截流与通道化（Dumb Pipe）**：自身无法建立直接面向终端消费级或企业工作流的应用入口，完全退化为被云巨头或聚合平台层低价集采的“无感知计算后台”。
- **资本断流与融资折价**：因商业化进展不及预期，在天量 CapEx 消耗殆尽前无法按预期估值完成后续融资，触发保护性清算或苛刻降轮融资（Down Round）。
- **核心大脑流失**：因战略分歧、商业化节奏争议或竞对激进挖角，主导关键架构突破的核心团队集体出走，研发飞轮中断。

## 红旗
- 仅依赖官方公布的静态学术基准刷榜，拒绝提供客户生产环境下的真实 A/B 测试盲测胜率。
- 宣称高 ARR，但实质收入大比例来自战略股东的关联采购、算力反向置换协议，或靠高额免费额度/补贴换取的“虚假活跃调用”。
- 推理服务贡献毛利为负，且随着业务用量规模放大，毛利率不仅未收敛改善，反而持续恶化。
- 存在不可撤销的超大额单一硬件/云协议，且合同违约赔偿条款足以击穿账面现金。
- 过去半年内顶尖研究员或系统工程骨干发生集群性离职，且未见等量级人才补进。

## 估值模型与退出惯例
- **三维情景模型**：
  * **牛市情景（AGI/独占级平台路线）**：保持前沿智能领先，占据底层操作系统地位，按 25–40x 远期经常性收入或以关键基础设施定价。
  * **基准情景（寡头共存路线）**：与 2-3 家闭源巨头并存，毛利逐步收敛至 60%–70%，按全球软件/平台龙头估值体系（10–18x 远期 ARR）校准。
  * **熊市情景（开源商品化/被管道化）**：智能溢价消退，退守垂直领域或算力重置成本清算，按重置净资产加技术 IP 打折计价。
- **退出路径**：前沿实验室体量通常超出一般产业收购方的承接极限，核心退出路径为万亿美元级科技巨头（Hyperscalers）在反垄断监管许可下的战略吸收合并，或以千亿美元级估值冲刺公开市场 IPO。入场价格必须在概率加权模型下论证是否具备至少 3–5 倍以上的价值提升空间。
