## 这一类型是什么
产品是一个前沿模型以及承载它的各类界面（消费级应用、企业 API、编码智能体、
云市场）的公司。价值由智能创造、通过分发捕获，并且只有在经济性能够经受住
token 价格下跌的情况下才能保住。

## 投资亮点通常落在哪里
- **行业地位** —— 在付费工作负载（编码、智能体工作、推理）上处于第一梯队的
  能力，以企业 API 份额和跨多代模型相对下一家实验室的领先幅度来衡量，而绝不
  以单一基准测试衡量。领先一代可能是运气；领先三代才是护城河。
- **市场空间与增速** —— 在每一种口径下市场都是真实的，但诚实的数字取决于
  口径。只展示一种口径的报告是在掩盖其他口径。
- **收入增长与质量** —— 数月内增长七倍在这一类公司中很常见；问题在于其中
  多少是自然增长、多少是补贴推理、多少经由可以随时改道的中间渠道。
- **护城河** —— 六个层次：研究、人才、算力、数据、分发、生态。前三者决定
  谁领先；后三者决定谁能在不领先的情况下胜出。每一层都要给出证据，而不是
  形容词。

## 各章节必须承载的类型专属指标
按工作负载划分的前沿地位（及其趋势）；企业 LLM API 份额；按业务线划分的
年化收入（消费级 / 企业 / API / 编码工具）；企业业务的净收入留存率(NRR)；
毛利率轨迹；每一美元收入对应的推理成本；每一美元算力对应的收入；现金、
消耗率与已承诺算力（美元与年数）；经由前两大渠道的收入占比。

## 经济性堆栈（必须展示）
收入 − 推理成本 − 训练摊销 − 云/GPU − 数据与授权 − 服务基础设施 = 贡献
毛利；再 − 研发 − 销售与市场 − 管理费用 = 经营现金流。说明哪些行是公司
披露的，哪些是报告的估算。

## 失败模式 -> 风险领域
技术：竞争对手的下一代模型抹平领先优势。竞争：价格通缩（token 价格下跌
快于用量增长）。集中度：两家编码中间渠道或一家云厂商承载四分之一的收入。
商业化：补贴推理始终无法实现正毛利。估值与退出：价格已经假设了多年计划
全部兑现；唯一的退出路径是以没有任何软件公司维持过的倍数进行 IPO。

## 可比公司与退出惯例
可比公司取其他实验室的私募估值标记（注明日期与买方）以及超大规模云厂商
的 AI 收入倍数；退出路径是以软件龙头倍数（8-15 倍远期收入）IPO——明确
说明入场价格对该倍数的假设是什么。
